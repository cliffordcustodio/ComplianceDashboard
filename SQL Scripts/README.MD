# SQL Scripts

## Overview

This folder contains all Microsoft SQL Server scripts required to create, populate, maintain, and support the Global Risk & Compliance Intelligence Platform database.

The scripts are organized by function to support database deployment, data loading, reporting, and ongoing maintenance.
